# Web Aspirasi MPK MAN 1 Bekasi (V2 - Glassmorphism & Lucide SVGs)

Aplikasi berbasis web modern untuk memfasilitasi program kerja (Proker) penampungan aspirasi siswa MAN 1 Bekasi secara transparan, akuntabel, dan profesional. Versi V2 ini dirancang dengan antarmuka **Glassmorphism**, transisi halus, serta mengganti seluruh emoji dengan **Lucide SVG Icons** yang tajam dan bersih.

## Fitur Unggulan V2
1. **Desain Glassmorphism & Smooth UI:** Efek latar belakang *blur*, kartu semi-transparan, serta animasi transisi hover yang elegan dan nyaman di mata.
2. **Zero Emojis (100% SVG Icons):** Seluruh ikon menggunakan Lucide SVG CDN yang memberikan kesan formal, rapi, dan modern.
3. **Mode Privasi Pintar (Anonim):** Siswa dapat menyampaikan saran secara rahasia untuk kenyamanan bersuara, namun sistem internal admin tetap mencatat validasi untuk mencegah spam/bullying.
4. **Mading Aspirasi Publik:** Menampilkan aspirasi yang telah divalidasi oleh pengurus MPK beserta kolom tanggapan resmi.
5. **Export Excel (.xlsx) 1-Klik:** Pengurus dapat mengunduh seluruh rekapitulasi aspirasi ke dalam file Excel (.xlsx) secara cepat tanpa instalasi server tambahan.
